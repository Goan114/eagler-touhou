# 首次使用须知

## 开始前请注意

### 1. 输入 touhou.vip 可以直接打开我们的网站。

以前使用的 /eagler-touhou 路径和 http 路径已经被抛弃。

### 2. 启动器支持离线访问，断网了也能打开。

启动器网页本身可以离线使用。游戏资源下载完成后，即可在无网络的情况下启动游戏。（但是可能得输入完整的链接 https://touhou.vip/ 才能离线访问。）

### 3. iOS 设备的触控问题已经修复。

现在按按钮应该不会打断游戏了。

### 4. 联机底层重做，现在手机也不会卡了。

可以不卡顿地和朋友一起用手机联机了。

### 5. 无法正常进行游戏时（尤其是用夸克、百度、系统浏览器时），请先查看页面右上角的[常见问题页](faq.html)。

如果看完了还是无法解决，再通过项目提供的反馈渠道报告问题。（反馈渠道也在常见问题里）
游戏攻略、存档问题、未来展望等也在常见问题里。

### 6. 我们急需会使用 AI 的开发者们。

我们目前很缺人，和 token。如果您有意向，欢迎参与项目的开发。
基本不需要什么技能，但是得有 token。欢迎通过[常见问题页](faq.html)和 Github 联系我们。

### 7. 请及时迁移您的存档数据。

迁移通道将会在 9 月 15 日左右关闭。（我知道已经过了时间了，但是再留一会通道）
