## 游戏闪退 / 卡顿 / 黑屏 / 加载异常 / 断触 等相关问题怎么办？
推荐优先使用以下浏览器：

- **Android**：Via（仅 < 5 MB） / [Edge](https://explore.microsoft.com/zh-cn/edge/download) / [Chrome](https://google.cn/chrome)

**Android 端不建议使用系统自带浏览器和各种国内浏览器。你也可以用，但可能会有一定的 BUG，如目前已知夸克浏览器会断触。**

- **iPhone / iPad**：Safari。由于 iOS 上的浏览器都使用 WebKit，换用其他浏览器通常不能绕过系统 WebKit 本身的兼容性限制。TH10（风神录）的 Worker / WebGL2 运行路径需要 **iOS / iPadOS 17 或更高版本**。

- **Windows**：Edge（系统自带） / [Chrome](https://google.cn/chrome) / [FireFox](https://www.firefox.com/)

若使用以上任一浏览器却仍然遇到了问题，请与我们反馈。

## 游戏可以“存档”吗？

STG游戏存档分两个概念。

- 一种是「一局中途停下，退出游戏，能在下一次打开游戏时继续以原先的残机等状态玩这一局吗？」。

这个答案是：**不能**。因为：原版/所有的STG类游戏机制便是如此。不过，一局游戏平均下来也就 25 分钟左右，很快就能打完。

 - 另一种是「我的游玩数据，比如通关记录、游玩时长等非游戏内状态数据，能保存下来吗？」

 这个答案是：**完全可以**。并且通过测试，和原版游戏互通。存档文件名由游戏决定，例如 TH06/TH07/TH08 使用各自的 `score.dat`，TH10 使用 `scoreth10.dat`。（**注：不同游戏存档不能混用!!** 如 TH06 的 `score.dat` 不能用在 TH07 上。）

## 下载不了资源怎么办？

如果已经安装过游戏，服务器很慢/暂时离线，客户端网络速度慢/无法上网时仍可直接启动本地版本；**首次安装、更新或补充缺失资源时**才需要等待服务器。

如果当前下载长时间没有进展，可以稍后重试，或使用页面提供的游戏包导入入口，或使用网络优化工具。请避免使用会接管网页下载的浏览器插件；目前已确认 Internet Download Manager 等插件可能与网页资源加载不兼容。

在支持 App Shell 离线恢复的环境中，站点成功打开过一次后，即使服务器随后不可用，刷新或重新打开页面也可以进入启动器（较新的浏览器几乎都支持）。普通 HTTP 环境不支持 Service Worker 时，刷新页面仍然需要服务器可达。

## 网络联机问题

网络联机使用了P2P（Peer to Peer，点对点）和中转服务器回退混合的联机技术。

联机前，请先确认 **是否使用了网络优化工具（如有，请关闭）** 和双方的 **NAT类型**。测试方法：[猫点饭](https://mao.fan/mynat) 或 [NAT Checker](https://natchecker.com/)。如您不了解 NAT 类型为什么会影响联机，可以查看[百度百科](https://baike.baidu.com/item/%E7%BD%91%E7%BB%9C%E5%9C%B0%E5%9D%80%E8%BD%AC%E6%8D%A2/2985755)。

如果双方的NAT类型为“Full Cone(NAT1)/(Port) Restricted Cone(NAT2/NAT3)”，那么P2P连接就有**极大概率成功**，在网络信号良好的情况下大概率不会出现任何联机问题。

如果双方有**任何一方**的 NAT 类型为“Symmetric(NAT4)”，那么 P2P 连接就有**极大概率失败**。即使网络信号良好，也容易回退到中转服务器来保证联机的可用性。随之，联机的流畅程度便有很大可能下降。

通俗讲：只有双方NAT数值之和小于等于6，才*有机会*进行P2P网络联机。

为防止联机观战导致游戏问题，**联机对战窗口仅在开始前有效**。即：在开启房间之后，只有在开始游戏前的时间内才可以进入联机房间的观战窗口，游戏开始后无法进行观战（进入观战的观战者可以一直看到结束）。
