# Quick Host

The default hosting path is intentionally opinionated. A normal operator should
not need the TH06/TH07/TH08 source repositories, Emscripten, CMake, Runtime
feature flags, or a handwritten server-feature file.

## Fixed input layout

Place the finished, original-resource-free Runtime Release and the three
legally-owned games in the Host Kit root:

```text
EaglerTouhou-Host/
├─ eagler-touhou.config.json # persistent operator configuration
├─ runtime-release/          # supplied by the Eagler Touhou Host package
│  ├─ runtime-release.json
│  └─ runtime/               # TH06/07 normal + MP, TH08 HTML/JS/WASM
├─ shared/                   # supplied by the Host package when present
│  ├─ unifont.otf
│  └─ japanese-font.otf
├─ games/
│  ├─ th06/                  # copy the TH06 installation here
│  ├─ th07/                  # copy the TH07 installation here
│  └─ th08/                  # copy the TH08 installation here
└─ dist/
   ├─ site/                  # generated; do not edit
   ├─ import-site/           # generated by npm run import
   └─ import/                # generated Import ZIPs
```

`eagler-touhou.config.json` and the three game directories are the persistent
operator inputs. `runtime-release` and `shared` are release artifacts supplied
by this project; generated output directories are disposable and must be
regenerated after configuration changes.

The default mode is `hosted` with TH06/TH07 `thprac` enabled and Japanese,
Simplified Chinese, and English prepared as the default language set. Quick Host
fails instead of silently dropping a default language when that preparation
cannot complete. OGG is generated automatically from the original music files.
Additional thcrap languages, alternate fonts, partial product sets,
external resource URLs, and other policy choices remain advanced deployment
options.

## Local hosted site

From the Launcher/Host package directory:

```powershell
npm run host
```

On the first run, Quick Host automatically runs `npm ci` when the locked Node.js
dependencies are missing. This installs the build tooling used to generate the
App Shell (including Workbox); it does not download original game content.

Python is a build prerequisite and is not downloaded by the Host Kit. Python
packages are isolated in the project-local `.deploy-python` environment. On
Windows, thtk 12 is fetched from its official upstream release on first use,
verified by SHA-256, and cached under `.cache/tools/thtk/12/`; the Host Kit does
not redistribute thtk binaries.

This validates the finished Runtime Release and all three game directories,
regenerates `dist/site`, verifies the deployment, then serves it only on
`127.0.0.1:8130` and opens:

```text
http://127.0.0.1:8130/eagler-touhou/
```

Using localhost is preferable to opening files directly: WebAssembly MIME,
Service Worker/security-context behavior, browser storage, iframe messaging,
and HTTP caching behave like a real site without exposing the server to the
network.

To only generate the static site:

```powershell
npm run host:build
```

To inspect required inputs and optional deployment services:

```powershell
npm run host:doctor
```

To generate the Import site and all three verified Import ZIPs:

```powershell
npm run import
```

## Public deployment

`dist/site` is the same verified static site used locally. Copy that directory
to the server; no Runtime compilation should occur on the public host. Do not
edit files inside `dist/site`; edit `eagler-touhou.config.json` and regenerate.

The repository's nginx configuration remains the default public-server
contract because the workload is almost entirely static and nginx handles the
required WASM/JS MIME types, compression, revalidation and immutable
content-addressed packs well. TLS may terminate at nginx, a CDN, or another
reverse proxy. The public deployment path should use HTTPS.

WebSocket relay and external Import-source URLs are ordinary Host configuration.
TURN remains server-managed. Advanced language/font/resource-policy or unusual
directory layouts can still use `deploy/Prepare-eagler-touhou-server.ps1`.

See `docs/HOST_DEPLOYMENT.md` for the nginx, relay, TURN, Import and update
workflow.

## Building a distributable Host Kit

This is a maintainer/release task, not an end-user step. A Host Kit embeds the
verified resource-free Runtime Release and redistributable shared font while
leaving the three game directories empty:

```powershell
.\deploy\Build-QuickHostKit.ps1 `
  -RuntimeRelease D:\Releases\runtime-release `
  -OutputDirectory D:\Releases\Eagler-Touhou-Host-Kit `
  -OutputArchive D:\Releases\Eagler-Touhou-Host-Kit.zip
```

The archive contains no original Touhou game data. Recipients extract it, run
`npm install`, copy their legally-owned games into the fixed folders, then run
`npm run host`.
