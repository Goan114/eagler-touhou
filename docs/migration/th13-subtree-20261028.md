The structural join `48e6481e16414a6717c69dfecd8c2c9135ccb6d8` connects this original root with current monorepo main. The [source record](th13-eagler-20261028.json) identifies that join and its export baseline.

The implementation follows PR #159 at `4fc0f57ce112541fd9397eb0b987fc30eea1f258`. Its implementation diff is applied on the current main; its projected parent chain is excluded. Ordinary follow-up commits contain no subtree control trailers.

Export and verify the source tree with:

```sh
git subtree split --prefix=ports/th13 --quiet HEAD
git merge-base --is-ancestor ca705e2339622348611590bb325dd013a95aa9a2 <split>
git rev-parse HEAD:ports/th13
git rev-parse <split>^{tree}
python tools/ports/check-history.py --base upstream/main
```

The final two tree IDs must match. TH13 is explicitly selected for validation builds and exposed on test publications. Japanese resources are prepared from the retail archive; the Launcher package includes both required shared fonts.
