# Asset provenance

This file covers the visual and font assets that are tracked by the public
Launcher repository. It is not permission to redistribute the original games.

## Generated original-game artwork

The Launcher uses the original games' title artwork, icons and character/title
imagery when a deployer builds a Hosted site. Those generated files are not
tracked in this public repository and are excluded from Runtime Release and
self-host source bundles.

- Source: the deployer's legally held Touhou Project game files.
- Examples: `assets/th06.ico`, TH06/TH07/TH08/TH10 card artwork generated by the
  host assembly pipeline.
- Ownership: Team Shanghai Alice / ZUN and the respective upstream projects.
- Publication: a deployer is responsible for the rights and policy of the site
  they publish. See `NOTICE.txt` and `THIRD_PARTY.md`.

## Fonts

The Launcher intentionally uses open font assets or project-generated subsets:

| Files | Upstream | License / notice |
| --- | --- | --- |
| `public/assets/fonts/unifont-site.woff2` | GNU Unifont | GNU General Public License version 2 or later with font embedding exception; see `public/assets/fonts/OFL-Unifont.txt`. |
| `public/assets/fonts/yatra-one-latin.woff2` | Yatra One | SIL Open Font License 1.1; see `public/assets/fonts/OFL-YatraOne.txt`. |
| `public/assets/fonts/chill-round-gothic-site-*.woff2` | 寒蝉全圆黑体 / ChillRound Gothic | SIL Open Font License 1.1; see `public/assets/fonts/OFL-ChillRoundGothic.txt`. |
| `public/assets/fonts/touhou98.woff2` | Project-maintained legacy pixel-font subset used by the Launcher. | Preserved from the established Launcher UI asset set; do not use as a source for publishing original game fonts. |

The full source fonts used by local subsetting scripts are operator/developer
inputs and are not part of the public Launcher deliverable.

Original game fonts such as `msgothic.ttc`, `NotoSansCJK-Regular.ttc` or private
font-conversion outputs must not be committed here. A deployer may include
locally prepared game fonts only in their generated game packages where allowed.
