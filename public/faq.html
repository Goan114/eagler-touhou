常见问题

感谢 Goan114 的整理和各位玩家的测试与反馈。

游戏闪退 / 卡顿 / 黑屏 / 加载异常 / 断触 等相关问题怎么办？

推荐优先使用以下浏览器：

Android：Via（仅 < 5 MB） / Edge / Chrome

（重要）Android 端不建议使用系统自带浏览器和各种国内浏览器。你也可以用，但可能会有一定的 BUG，如目前已知夸克浏览器会断触。

Windows：Edge（系统自带） / Chrome / Firefox

若使用以上任一浏览器却仍然遇到了问题，请与我们反馈。

游戏有操作说明 / 攻略吗？游戏剧情在哪看？

本网站有自带的操作说明，启动游戏后，点击右上角的 "?" 图标，即可查看。

如果想看原版游戏自带的说明和游戏剧情，可以访问东方Project 附带文档总览页。

关于游戏攻略，可以前往 THBwiki 中的游戏攻略页查看。

如果您对东方Project的世界观和游戏玩法了解不深，我们更建议您先去查阅 THBwiki，其对游戏机制的解析十分全面易懂，然后再进行游戏。但是如果您要看 THBwiki 里的「东方ProjectSTG基础百科」，我们建议直接从第一章开始看，并且直接跳过第一章开头的游戏称谓表。

游戏可以“存档”吗？

STG游戏存档分两个概念。

一种是「一局中途停下，退出游戏，能在下一次打开游戏时继续以原先的残机等状态玩这一局吗？」，这个答案是：不行。原版/所有的STG类游戏机制便是如此。不过，一局游戏平均下来也就 25 分钟左右，很快就能打完。

另一种是「我的游玩数据，比如通关记录、游玩时长等非游戏内状态数据，能保存下来吗？」，这个答案是：完全可以，并且通过测试，和原版游戏互通。存档文件为：“score.dat”。注：不同游戏存档不能混用!! （如th06的score.dat不能用在th07上）。

会有风神录、地灵殿等其他正作/小数点作/格斗作/二次创作/新典......吗？

对于较旧的正作，我们正在尽力将其移植到网页端。上线时间不定。

对于较新的正作/小数点作/格斗作，我们暂不考虑。但是仍然作为我们的To-Do List中的一环。（注：即使移植了格斗作，我们也不能设置联机。如果可能有移植，那格斗作的复杂连招、极为严苛的搓招和大量的按键导致格斗作人性化移植到移动端根本不可能。）

对于新典，我们不会移植。因为版权风险太大，并且性价比不高。

对于二次创作，我们不会移植。因为太多太杂，并且性价比不高

下载不了资源怎么办？

如果已经安装过游戏，服务器很慢/暂时离线，客户端网络速度慢/无法上网时仍可直接启动本地版本；首次安装、更新或补充缺失资源时才需要等待服务器。

如果当前下载长时间没有进展，可以稍后重试，或使用网络优化工具，或使用页面提供的游戏包导入入口。请避免使用会接管网页下载的浏览器插件；目前已确认 Internet Download Manager 等插件可能与网页资源加载不兼容。

在支持 App Shell 离线恢复的环境中（较新的浏览器基本都支持），站点成功打开过一次后，即使服务器随后不可用，刷新或重新打开页面也可以进入启动器。普通 HTTP 环境不支持 Service Worker 时，刷新页面仍然需要服务器可达。

永夜抄的部分问题

由于永夜抄上游代码质量不佳，在游戏中可能会出现部分错误/bug。以下是目前已知的部分错误，反馈问题时无需提及：

部分弹幕不可见（慧音部分符卡、魔理沙部分激光、永琳部分符卡和终符、辉夜部分符卡）。

手机端渲染问题（上半部分出现不断闪烁的坏点，截屏不可见）。

显示"Full Power Mode"等游戏内字符时，状态栏会暂停更新。

Boss战对白时屏幕背景会变黑/背景卡住。

游戏通关（无论是否使用续关），游戏会卡住30-60秒。

五面进六面的Final A和Final B的选项在手机端无法选择。

小关通关时的结算画面显示有误。

网络联机问题

网络联机使用了P2P（Peer to Peer，点对点）和中转服务器回退混合的联机技术。

联机前，请先确认是否使用了网络优化工具（如有，请关闭）和双方的NAT类型。

测试方法：猫点饭 或 NAT Checker

如您不了解NAT类型为什么会影响联机，可以查看百度百科。

如果双方的NAT类型为“Full Cone(NAT1)/(Port) Restricted Cone(NAT2/NAT3)”，那么P2P连接就有极大概率成功，在网络信号良好的情况下大概率不会出现任何联机问题。

如果双方有任何一方的NAT类型为“Symmetric(NAT4)”，那么P2P连接就有极大概率失败。即使网络信号良好，也容易回退到中转服务器来保证联机的可用性。随之，联机的流畅程度便有很大可能下降。

通俗讲：只有双方NAT数值之和小于等于6，才有机会进行P2P网络联机。

为防止联机观战导致游戏问题，联机对战窗口仅在开始前有效。即在开启房间之后，只有在开始前的时间内才可以进入联机房间的观战窗口，开始后无法进行观战（进入观战的观战者可以一直看到结束）。
